# orm-micronaut-tx sample ownership

[English](README.md) | [简体中文](README.zh-CN.md)

This module supplies transaction boundaries for the Micronaut ORM bridge. The runnable scenario is owned by [micronaut-web](https://github.com/normlanguage/micronaut-web/tree/main/samples) in its `samples/` directory; use that example to observe the behavior through the public API.

The module identity and pinned dependencies are defined in [module.norm](../orm/micronaut/tx/module.norm).
